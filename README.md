# دورة حياة النبات

فيديو تعليمي باللغة العربية يشرح دورة حياة النبات من البذرة إلى الإنبات والنمو والإزهار وتكوين البذور الجديدة.

## الملفات

| الملف | الوصف |
|---|---|
| `plant_lifecycle_ar.mp4` | الفيديو النهائي بدقة 1080p60 مع تعليق صوتي عربي وترجمة مضمّنة |
| `subtitles.srt` | ملف الترجمة العربية الخارجي |
| `video.py` | كود Manim Community Edition القابل لإعادة الاستخدام |
| `scenes.md` | مخطط المشاهد ومزامنة الصوت |
| `audio/` | المقاطع الصوتية العربية المنفصلة لكل مشهد |

## المواصفات

مدة الفيديو 93.28 ثانية، ويحتوي الملف النهائي على مسارات H.264 للفيديو وAAC للصوت و`mov_text` للترجمة.

## إعادة الإنتاج

يتطلب المشروع Python وManim Community Edition وFFmpeg. يمكن إعادة اختبار المشاهد باستخدام:

```bash
python3 /home/ubuntu/skills/manim-animator/scripts/render_scenes.py \
  --code video.py --out output --timeout 180
```

> ملاحظة: ملف الفيديو النهائي هو `output/plant_lifecycle_ar.mp4`.
